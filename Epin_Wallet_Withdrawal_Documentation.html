E-Pin, E-Wallet आणि Withdrawal सिस्टीम फ्लो व टेक्निकल डॉक्युमेंटेशन
Application Flow & Logic Documentation
1 E-PIN (इलेक्ट्रॉनिक पिन) चे काम व संपूर्ण फ्लो

E-PIN काय आहे? E-PIN हा एक सुरक्षित युनिक डिजिटल कोड (Token/Voucher) असतो, ज्यामध्ये विशिष्ट रक्कम किंवा पॅकेज व्हॅल्यू असते. नवीन मेंबरचे रजिस्ट्रेशन/ॲक्टिव्हेशन आणि वॉलेट रिचार्ज करण्यासाठी याचा वापर होतो.

👨‍💼 Admin Flow
  • Generate E-Pin (admin/generate_epin): ॲडमिन विशिष्ट पॅकेज व रक्कमेचे अनेक युनिक पिन एका क्लिकवर तयार करू शकतो.
  • Request Approval (admin/epinn): मेंबर्सनी पाठवलेल्या पेमेंट रिक्वेस्ट्स तपासून ॲडमिन पिन Issue / Approve करतो.
  • E-Pin Management: सर्व Un-used आणि Used पिन्सचा रिपोर्ट पाहणे, एडिट किंवा डिलीट करणे.
👤 Customer / Member Flow
  • E-Pin Request: मेंबर बँक किंवा UPI द्वारे पेमेंट करून ॲडमिनकडे E-Pin ची मागणी करू शकतो.
  • Account Activation: नवीन मेंबरची नोंदणी किंवा आयडी अपग्रेड करण्यासाठी E-PIN वापरला जातो (site/register).
  • Wallet Top-Up: पिन टाकून थेट स्वतःचे मेन किंवा प्रॉडक्ट वॉलेट रिचार्ज करता येते.
  • E-Pin Transfer: शिल्लक पिन आपल्या डाऊनलाईन मेंबर्सना ट्रान्सफर करता येतात.
2 E-WALLET (इलेक्ट्रॉनिक वॉलेट) चे काम व संपूर्ण फ्लो

E-Wallet काय आहे? सॉफ्टवेअरमधील प्रत्येक मेंबरचे डिजिटल लेजर खाते म्हणजे E-Wallet. सिस्टीममध्ये २ मुख्य वॉलेट्स आहेत:
• Main Wallet: सर्व कमिशन (Direct, Level, Binary) जमा होते; यातून बँक विड्रॉल करता येते.
• Product Wallet: केवळ ई-कॉमर्स / होमशॉपवरून प्रॉडक्ट्स खरेदी करण्यासाठी वापरले जाते.

👨‍💼 Admin Flow
  • Manage Funds (wallet/manage_wallet_fund): कोणत्याही युझरच्या खात्यात रक्कम Credit (जमा) किंवा Debit (कमी) करणे.
  • Deposit Approval (wallet/support): ऑफलाइन बँक डिपॉझिट रिक्वेस्ट्स तपासून अप्रूव्ह/रिजेक्ट करणे.
  • Fund Transfer: दोन मेंबर्समध्ये फंड ट्रान्सफर करणे.
  • Audit Logs: सर्व ट्रॅन्झॅक्शन्सचा संपूर्ण ऑडिट ट्रेल पाहणे (wallet_transaction).
👤 Customer / Member Flow
  • Add Funds: E-Pin, Razorpay गेटवे किंवा QR कोड द्वारे वॉलेट टॉप-अप करणे.
  • Wallet-to-Wallet Transfer: मेन वॉलेटमधील इन्कम प्रॉडक्ट वॉलेटमध्ये शॉपिंगसाठी हलवणे (wallet/withdraw_payouts).
  • Product Purchase: होमशॉप किंवा कार्टमध्ये पेमेंट करताना वॉलेट शिल्लक वापरणे.
  • Transaction Passbook: क्रेडिट/डेबिट इतिहास तपासणे.
3 WITHDRAWAL (विड्रॉल / पे-आउट) चे काम व संपूर्ण फ्लो

Withdrawal काय आहे? मेंबर्सनी कमवलेले कमिशन कायदेशीर टॅक्स वजा करून सुरक्षितपणे त्यांच्या बँक किंवा UPI खात्यात ट्रान्सफर करण्याची ही प्रक्रिया आहे.

👨‍💼 Admin Flow
  • Payout List (income/withdraws_list): सर्व प्रलंबित (Un-Paid) विड्रॉल रिक्वेस्ट्स, बँक डिटेल्स व Net रक्कम तपासणे.
  • Process & Mark Paid (income/pay): प्रत्यक्ष बँक ट्रान्सफर (NEFT/IMPS) करून UTR/Txn ID नोंदवून स्टेटस Paid करणे.
  • Reject & Auto Refund (income/reject_withdraw): डिटेल्स चुकीच्या असल्यास रिजेक्ट करणे; रिजेक्ट होताच रक्कम मेंबरच्या वॉलेटमध्ये परत जमा (Auto Refund) होते.
👤 Customer / Member Flow
  • KYC Validation: विड्रॉलसाठी प्रोफाइलमध्ये व्हॅलिड PAN Card (tax_no) असणे आवश्यक.
  • Request Amount: रक्कम किमान मर्यादेपेक्षा (min_withdraw) जास्त असावी.
  • Instant Wallet Lock: रिक्वेस्ट सबमिट होताच वॉलेटमधून रक्कम तात्काळ Debit होते.
  • Status Tracking: पे-आउटचे स्टेटस (Un-Paid / Paid / Rejected) पाहणे.
📊 कोडमधील टॅक्स व निव्वळ रक्कमेचे सूत्र (Deduction Calculation):
• Admin Tax: (Gross Amount × Admin Charge %) / 100
• TDS Tax: (Gross Amount × Payout Tax %) / 100
• Total Deductions: Admin Tax + TDS Tax
• Net Payable (बँकेत जमा होणारी रक्कम): Gross Amount − Total Deductions
4 सविस्तर स्टेप-बाय-स्टेप फ्लोचार्ट्स (Detailed Step-by-Step Flow)

🔹 1. E-PIN Lifecycle Flow:

पायरी १: ॲडमिन admin/generate_epin वरून E-Pin तयार करतो किंवा युझरने केलेली विनंती admin/epinn_approve द्वारे मंजूर करतो.
⬇️ (डेटाबेस: epin टेबलमध्ये status = 'Un-used')
पायरी २: मेंबर आपल्या डॅशबोर्डवर (member/unused_epin) पिन पाहतो किंवा डाऊनलाईनला ट्रान्सफर (member/epin_transfer) करतो.
⬇️ (पिन वापरताना)
पायरी ३: रजिस्ट्रेशन (site/register) किंवा वॉलेट टॉप-अप (wallet/topup_epin_wallet) मध्ये पिन वापरला जातो.
⬇️ (अंतिम स्थिती)
पायरी ४: सिस्टीम पिनचे स्टेटस status = 'Used', used_by आणि used_time अपडेट करते.

🔹 2. E-Wallet Fund Flow:

फंड येणे (Credit): कमिशन इन्कम (Direct, Level, Binary) किंवा E-Pin/Gateway/Admin डिपॉझिट ➔ wallet (Main Balance) मध्ये जमा.
⬇️ (वापराचे दोन मार्ग)
मार्ग A (Shopping):
Main Wallet ➔ Product Wallet Transfer (wallet/withdraw_payouts) ➔ HomeShop/Cart द्वारे खरेदी.
मार्ग B (Cash Out):
Main Wallet ➔ Bank Withdrawal Request (wallet/withdraw_payouts) ➔ थेट बँक खात्यात.

🔹 3. Withdrawal / Payout Flow:

पायरी १ (मेंबर रिक्वेस्ट): मेंबर PAN Card तपासून विड्रॉल रिक्वेस्ट टाकतो. Gross Amount लगेच Main Wallet मधून वजा (Debit) होते.
⬇️ (डेटाबेस: withdraw_request मध्ये status = 'Un-Paid')
पायरी २ (ॲडमिन पडताळणी): ॲडमिन income/withdraws_list मध्ये बँक तपशील आणि Net Payable रक्कम पाहतो.
⬇️ (ॲडमिन ॲक्शन)
✅ मंजूर (Paid):
ॲडमिन बँकेतून NEFT/UPI द्वारे पेमेंट करतो व UTR/Txn ID टाकून स्टेटस Paid करतो.
❌ नामंजूर (Rejected):
स्टेटस Rejected होते आणि मूळ रक्कम युझरच्या वॉलेटमध्ये Auto-Refund होते.
घटक (Module) डेटाबेस टेबल्स (DB Tables) मुख्य कार्य (Primary Purpose)
E-PIN epin, epin_request आयडी ॲक्टिव्हेशन, रजिस्ट्रेशन आणि व्हाउचर Top-Up साठी.
E-Wallet wallet, product_wallet, wallet_transaction कमिशन साठवणे, बॅलन्स मॅनेजमेंट आणि प्रॉडक्ट शॉपिंग.

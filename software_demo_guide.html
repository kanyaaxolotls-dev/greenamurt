MLM & Direct Selling Software — Admin & Member Complete User Guide (मराठी)

⚠️ सॉफ्टवेअरमधील ऍक्टिव्हेशनचे अचूक नियम (Code Rules):
  • ID Activation पद्धती: आयडी ऍक्टिव्हेट फक्त E-Pin द्वारे किंवा Online Exam (Pass / Skip Exam) द्वारे होतो. (E-Wallet द्वारे आयडी Active केला जात नाही).
  • E-Wallet चा वापर: E-Wallet चा वापर फंड डिपॉझिट (Add Money), Member-to-Member ट्रान्सफर आणि पेआउट विड्रॉलसाठी होतो.

१. Registration & Login (नोंदणी व लॉगिन)

नोंदणी URL: site/register | लॉगिन URL: site/login

  • १ Sponsor ID: कोणाच्या रेफरलने जॉईन होत आहे तो ID टाकल्यावर स्पॉन्सरचे नाव आपोआप येते.
  • २ Position: बायनरी लेगसाठी Left (A) किंवा Right (B) सिलेक्ट करा.
  • ३ फॉर्म डिटेल्स: Name, Phone No, Email, Password (min 5 chars), Country, State, District, Tehsil आणि Package निवडा.
  • ४ ३-IDs नियम (Code Rule): एका व्यक्तीच्या माहितीवर जास्तीत जास्त ३ आयडी अलाऊड आहेत. पहिला मेन आयडी, दुसरा डाव्या बाजूला आणि तिसरा उजव्या बाजूला ऑटो-प्लेस होतो.
  • ५ नोंदणीनंतर: सिस्टीम युनिक Member ID देते. सुरुवातीला स्टेटस Inactive (Pending) असतो.
ॲडमिन पॅनल गाईड (Admin Side Walkthrough)
Admin Role

Admin: E-Pin Management (पिन बनवणे व पाठवणे)

  • १ E-Pin तयार करणे (admin/generate_epin): Amount / Package निवडा, पिन्सची संख्या (Quantity) टाका आणि Generate करा. या पिन्स 'Un-used' म्हणून तयार होतात.
  • २ E-Pin ट्रान्सफर करणे (admin/transfer_epin): मेंबरचा User ID टाका आणि तयार केलेल्या पिन्स त्या मेंबरच्या खात्यात ट्रान्सफर करा.
  • ३ Pin Reports: admin/unused_epin (शिल्लक पिन्स) व admin/used_epin (वापरलेल्या पिन्सची हिस्ट्री).

Admin: Quiz & Activation Approvals

  • १ Quiz Payment Requests (admin/quiz_payment_requests): मेंबर्सने भरलेल्या एक्झाम फीचे स्क्रीनशॉट व UTR तपासा आणि 'Approve' करा.
  • २ Direct Exam Access (admin/manual_quiz_approve): पेमेंट न घेता एखाद्या मेंबरला थेट एक्झाम ऍक्सेस द्यायचा असल्यास User ID टाकून मॅन्युअली अप्रूव्ह करा.

Admin: E-Wallet & Bank Deposit Requests

  • १ Bank Deposit Requests (admin/deposit_history / wallet/wallet_requests): मेंबर्सने बँक खात्यात भरलेल्या पैशांची विनंती तपासा आणि 'Approve' करा. रक्कम लगेच मेंबरच्या वॉलेटमध्ये जमा होते.
  • २ Manage Wallet Fund (wallet/manage-wallet-fund): ॲडमिन कोणत्याही मेंबरच्या खात्यात मॅन्युअली पैसे ॲड (Credit) किंवा कट (Debit) करू शकतो.

Admin: Payouts & Withdrawal Release

  • १ Make Payment / Pending Withdrawals (income/make-payment किंवा income/withdraws_list/Un-Paid): येथे विड्रॉल मागितलेल्या सर्व मेंबर्सची यादी (बँक तपशील, IFSC, पॅन, नेट रक्कम) दिसते.
  • २ Excel Export: ही फाईल Excel मध्ये डाऊनलोड करून बँकेतून NEFT / IMPS ट्रान्सफर करा.
  • ३ Mark as Paid: पैसे पाठवल्यावर ॲडमिन 'Paid' मार्क करतो.
मेंबर पॅनल गाईड (Member Side Walkthrough)
Member Role

Member: E-Pin द्वारे आयडी Active करणे

मेनू: e-PINs ➡️ Active e-PINs (member/unused-epin)

  • १ Active e-PINs पेजवर जा.
  • २ ज्याचा आयडी ऍक्टिव्हेट करायचा तो User ID टाका (स्वतःचा किंवा डाऊनलाईनचा).
  • ३ उपलब्ध E-Pin निवडा आणि 'Activate ID' वर क्लिक करा.
काय होते? आयडी Active होतो, पिन 'Used' मार्क होते, `product_sale` मध्ये ऑर्डर तयार होते आणि स्पॉन्सरला Direct Income व PV/BV क्रेडिट होतात.

Member: E-Wallet Module चा वापर

  • १ Add Money / Topup (member/topup-wallet): कंपनीच्या बँकेत पैसे पाठवून UTR व स्क्रीनशॉट सबमिट करा. ॲडमिनने अप्रूव्ह केल्यावर वॉलेटमध्ये बॅलन्स वाढेल.
  • २ Wallet Transfer (wallet/transfer-balance): इतर कोणत्याही मेंबरचा User ID टाकून वॉलेटमधील फंड ट्रान्सफर करा.
  • ३ Wallet Transactions (wallet/trans_history): क्रेडिट-डेबिट पासबुक तपासा.

Member: Payouts & Bank Withdrawal

मेनू: E-Wallet ➡️ Withdraw payout request (wallet/withdraw-payouts)

  • १ अटी: प्रोफाइलमध्ये PAN Card Number आणि Bank A/C Details सेव्ह असणे बंधनकारक आहे. वॉलेट बॅलन्स किमान विड्रॉल मर्यादेपेक्षा (Min Withdraw) जास्त असावे.
  • २ Deductions: सिस्टीम आपोआप TDS आणि Admin Charges वजा करून Net Payable दाखवते.
  • ३ Submit Request: बँक निवडून रिक्वेस्ट सबमिट करा. ती ॲडमिनकडे जाते.
  • ४ Payout Report (wallet/withdrawal-list): बँक खात्यात पैसे जमा झाल्यावर स्टेटस 'Paid' दिसेल.
